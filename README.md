# Librería - Aplicación de Prueba

Aplicación desarrollada como práctica para la asignatura de **Aplicaciones Móviles**, 
que simula el funcionamiento básico de una librería.

## Información Académica

- **Autor:** Eduardo Josué López López
- **Curso:** Séptimo A
- **Asignatura:** Aplicaciones Móviles

## Descripción

Este proyecto es una lección de práctica orientada al aprendizaje del desarrollo 
de aplicaciones móviles, aplicando conceptos fundamentales de Android.

## Tecnologías utilizadas

- Kotlin
- Android Studio
- Gradle

## Cómo ejecutar el proyecto

1. Clonar este repositorio
2. Ábrirlo en Android Studio
3. Sincronizar las dependencias de Gradle
4. Ejecutar la aplicación en un emulador o dispositivo físico
